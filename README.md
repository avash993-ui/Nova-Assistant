## 🇬🇧 English

**NOVA – Avash Studio**

NOVA is a desktop AI assistant built to make working with your computer easier. You can talk to it, ask questions, and interact with it using either voice or text.

The new version of NOVA supports **Persian and English**, with support for more languages being added in future updates. You can activate the assistant by saying **"Hey Nova"** or its Persian equivalent, **"هی نوا."**

NOVA uses APIs to communicate with AI models and is designed with a flexible structure so new features can be added over time.

**Features:**
- Persian and English support
- More languages coming in future versions
- Wake word support: "Hey Nova" / "هی نوا"
- AI conversations
- Voice commands
- Desktop user interface
- API integration
- Extensible and ready for future features

NOVA is created and developed by **Avash Studio**.

## 🇷🇺 Русский

**NOVA – Avash Studio**

NOVA — это ИИ-ассистент для компьютера, созданный для того, чтобы упростить работу с ним. Вы можете разговаривать с ним, задавать вопросы и взаимодействовать голосом или текстом.

Новая версия NOVA поддерживает **персидский и английский языки**, а поддержка других языков добавляется в будущих обновлениях. Активировать ассистента можно фразой **«Hey Nova»** или её персидским эквивалентом **«هی نوا»**.

NOVA использует API для связи с моделями ИИ и спроектирован с гибкой архитектурой, позволяющей со временем добавлять новые функции.

**Возможности:**
- Поддержка персидского и английского языков
- В будущих версиях появятся другие языки
- Активация по слову «Hey Nova» / «هی نوا»
- Диалог с ИИ
- Голосовые команды
- Интерфейс для рабочего стола
- Интеграция с API
- Расширяемая архитектура для будущих функций

NOVA создаётся и разрабатывается студией **Avash Studio**.
