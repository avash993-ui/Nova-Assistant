# نوا - نسخه‌ی کامپیوتر

یه اپ دسکتاپ (Electron) با همون قابلیت‌های نسخه‌ی اندروید: چت، اتصال به هر API سازگار با OpenAI،
میانبرها، حافظه، حالت توسعه‌دهنده، و یه پنجره‌ی شناور که با گفتن «هی نوا» باز میشه.

## اجرای مستقیم روی کامپیوتر خودت (برای تست)

۱. [Node.js](https://nodejs.org) رو نصب کن (نسخه‌ی ۱۸ به بالا).
۲. داخل همین پوشه (`nova-desktop`) این دستورها رو بزن:

```
npm install
npm start
```

برنامه باز میشه. تنظیماتت (API، رمز، گفتگوها) توی یه فایل محلی ذخیره میشه، نه آنلاین.

## ساختن نسخه‌ی نصبی (exe/dmg/AppImage)

```
npm run dist
```

فایل نصبی توی پوشه‌ی `dist/` ساخته میشه.

### یا بدون نصب هیچی روی کامپیوترت: با GitHub Actions
این پروژه یه workflow آماده داره (`.github/workflows/build-desktop.yml`)، دقیقاً مثل همونی که برای
اندروید داری. کافیه این پوشه رو توی گیت‌هاب push کنی؛ یه فایل exe برات می‌سازه که از تب Actions
دانلودش می‌کنی.

## نکته‌ی مهم درباره‌ی میکروفون (صادقانه بگم)

تشخیص گفتار (Web Speech API) که برای «هی نوا» و دکمه‌ی میکروفون استفاده شده، روی **کروم اصلی
گوگل** همیشه کار می‌کنه، چون کروم یه کلید خصوصی گوگل داخلش داره. ولی Electron از یه نسخه‌ی متفاوت
(Chromium بدون اون کلید) استفاده می‌کنه، و روی بعضی کامپیوترها ممکنه تشخیص گفتار خطای "network" بده
و کار نکنه، هرچند چت متنی و همه‌ی قابلیت‌های دیگه کاملاً درست کار می‌کنن.

اگه این اتفاق افتاد:
- تایپ کردن همیشه کار می‌کنه، هیچ قابلیتی از دست نمیره.
- اگه واقعاً میکروفون لازمه، می‌تونی خودِ `src/index.html` و `src/overlay.html` رو مستقیم توی
  **کروم گوگل** باز کنی (نه Electron) تا تشخیص گفتار مطمئناً کار کنه؛ فقط پنجره‌ی شناور و آیکون
  سینی سیستم اون‌جا در دسترس نیست.
- بهم بگو اگه این مشکل رو دیدی، می‌تونیم یه سرویس تشخیص گفتار ابری (مثل همون API که برای چت
  وصل کردی) جایگزینش کنیم که روی هر کامپیوتری تضمینی کار کنه.

## رمز توسعه‌دهنده

رمز پیش‌فرض `3993` هست. مثل نسخه‌ی اندروید، به‌شکل هش (نه متن خام) روی کامپیوتر ذخیره میشه. از
صفحه‌ی تنظیمات می‌تونی رمز رو عوض کنی.
